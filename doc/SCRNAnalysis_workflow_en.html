Introduction

This vignette shows a complete SCRNAnalysis workflow using pbmc_small, a small dataset included in Seurat. The dataset is used as a lightweight example to demonstrate the main analysis steps without requiring external downloads.

The workflow includes:

  1. loading data from a Seurat object;
  2. converting the data to SingleCellExperiment;
  3. creating a ScDeconvExperiment object;
  4. filtering genes and cells;
  5. normalizing counts and applying a log-transform;
  6. selecting highly variable genes;
  7. clustering cells;
  8. annotating cells using Seurat label transfer;
  9. comparing clusters with predicted cell-type labels;
  10. visualizing the relationship between clusters and annotations.

pbmc_small is suitable for a vignette because it is very small. The labels stored in its metadata are used here only to demonstrate the workflow.

To make the reference usable for Seurat label transfer, we apply minimal preprocessing.

reference <- Seurat::NormalizeData(reference, verbose = FALSE)
reference <- Seurat::FindVariableFeatures(reference, verbose = FALSE)
reference <- Seurat::ScaleData(reference, verbose = FALSE)
reference <- Seurat::RunPCA(reference, verbose = FALSE)

Create a ScDeconvExperiment object

The ScDeconvExperiment() constructor defined in the package expects a SingleCellExperiment object containing a counts assay. For this reason, we first extract the counts from the Seurat object, then create a SingleCellExperiment, and finally convert it to the package-specific class.

The helper function get_seurat_assay_data() keeps the code compatible with both Seurat v5, which uses layer, and earlier versions, which use slot.

get_seurat_assay_data <- function(x, assay = SeuratObject::DefaultAssay(x), layer = "counts") {
  tryCatch(
    SeuratObject::GetAssayData(x, assay = assay, layer = layer),
    error = function(e) SeuratObject::GetAssayData(x, assay = assay, slot = layer)
  )
}

counts <- get_seurat_assay_data(reference, assay = "RNA", layer = "counts")
query_sce <- SingleCellExperiment::SingleCellExperiment(assays = list(counts = counts))
query <- ScDeconvExperiment(query_sce)

Filter genes and cells

The first quality-control step removes genes expressed in too few cells. The second step removes cells with an abnormal number of detected genes, using percentile-based thresholds.

query <- filterLowExpressionGenes(
  query,
  assay_name = "counts",
  min_count = 1,
  lower_percentile = 0.01
)
query <- filterCellsByDetectedGenes(
  query,
  assay_name = "counts",
  min_count = 1,
  lower_percentile = 0.01,
  upper_percentile = 0.99
)

Normalize counts and apply a log-transform

After filtering, counts are normalized to a total of 10,000 counts per cell and stored in normcounts. A log-transform is then applied and stored in logcounts.

query <- normalizeToTotal(query, target_total = 1e4)
query <- logTransform(query, assay_name = "normcounts", pseudo_count = 1, base = 2)

Cluster cells

performClustering() first computes a PCA using scater::runPCA() and then applies the selected clustering algorithm. Here, k-means clustering is used with seven clusters so that the comparison plots show a more detailed relationship with the reference annotations.

n_pcs <- min(5, ncol(query) - 1, sum(SummarizedExperiment::rowData(query)$is_hvg) - 1)
n_pcs <- max(2, n_pcs)

query <- performClustering(
  object = query,
  assay_name = "logcounts",
  algorithm = "kmeans",
  use_hvg = TRUE,
  n_hvg = n_hvg,
  n_pcs = n_pcs,
  n_clusters = 7,
  cluster_column = "cluster",
  pca_name = "PCA"
)

table(SummarizedExperiment::colData(query)$cluster)
#> 
#>  1  2  3  4  5  6  7 
#> 30  8 13  6  9  3  9

Annotate cells with Seurat

Cell labels are transferred from the Seurat reference to the query object. performDeconvolution() stores the predicted labels in colData(query)$seurat_label and the maximum prediction score in colData(query)$seurat_label_score.

dims <- seq_len(min(10, ncol(SeuratObject::Embeddings(reference, "pca"))))

query <- performDeconvolution(
  object = query,
  reference = reference,
  flavour = "seurat",
  reference_label_column = "letter.idents",
  label_column = "seurat_label",
  dims = dims
)

table(SummarizedExperiment::colData(query)$seurat_label)
#> 
#>  A  B 
#> 48 30
summary(SummarizedExperiment::colData(query)$seurat_label_score)

#>  0.6942  0.8479  0.9251  0.9094  0.9893  1.0000

plotClusterCellTypeDendrogram(query, metadata_name = "cluster_cell_type_comparison", value = "row_proportions", margin = "clusters")

plotClusterCellTypeAlluvial(query, metadata_name = "cluster_cell_type_comparison")

SingleR alternative

The workflow above uses flavour = "seurat". The same function can also be used with flavour = "singler", provided that the reference is a SummarizedExperiment or SingleCellExperiment object with an annotation column in colData().

This chunk is not evaluated by default because the main vignette uses Seurat, but it shows the equivalent call for SingleR.

reference_sce <- Seurat::as.SingleCellExperiment(reference)

if (!"logcounts" %in% SummarizedExperiment::assayNames(reference_sce)) {
  ref_logcounts <- get_seurat_assay_data(reference, assay = "RNA", layer = "data")
  SummarizedExperiment::assay(reference_sce, "logcounts") <- ref_logcounts
}

SummarizedExperiment::colData(reference_sce)$cell_type <- reference$letter.idents

query <- performDeconvolution(
  object = query,
  reference = reference_sce,
  flavour = "singler",
  reference_label_column = "cell_type",
  assay_name = "logcounts",
  ref_assay_name = "logcounts",
  label_column = "singler_label"
)

table(SummarizedExperiment::colData(query)$singler_label)
